# EthicsComitee

## Запуск

Нужен Node.js 18+ (https://nodejs.org). Параметры ИИ лежат в файле `.env` (его читает сам сервер, экспортировать переменные не нужно).

- Windows: двойной клик по `start.bat`
- Linux/macOS: `./start.sh` или `npm start`

Откройте http://localhost:3000 (не открывайте `index.html` как файл).

## Настройка ИИ

По умолчанию используется Gemini через его OpenAI-совместимый endpoint: `AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai`, `AI_MODEL=gemini-3.8-flash`, ключ в `AI_API_KEY`. Любой другой OpenAI-compatible провайдер подключается изменением этих трёх строк. Ключ хранится только на сервере (`.env` не отдаётся браузеру и указан в `.gitignore`).

## Локальная база нормативных актов
`data/sources.json` содержит метаданные и фрагменты для поиска. Полные извлечённые тексты лежат в `data/documents/`:
- Закон РК «О государственной службе Республики Казахстан» от 19.05.2026 № 290-VIII;
- Закон РК «О противодействии коррупции» от 18.11.2015 № 410-V;
- Постановление Правительства РК от 26.07.2002 № 833 о правилах учета, хранения, оценки и дальнейшего использования имущества;
- Указ Президента РК от 02.01.2023 № 81 об Этическом кодексе сотрудников правоохранительных органов, органов гражданской защиты и государственной фельдъегерской службы;
- Указ Президента РК от 29.12.2015 № 153 об Этическом кодексе государственных служащих и Положении об уполномоченном по этике.

Корпус включает пять документов, предоставленных для этой версии сайта. Тексты документов сохранены в UTF-8 в `data/documents/`, а структурированные фрагменты для поиска — в `data/sources.json`. Ссылки на карточки НПА ведут на официальный сайт `adilet.zan.kz`; сайт не загружает оттуда дополнительные сведения. Автоматическое обновление законодательства не выполняется.

## Архитектура и ограничения
- `index.html` + `css/` + `js/` — интерфейс без сторонних клиентских библиотек (см. «Структура проекта» ниже).
- `server.js` — API proxy, retrieval по локальным выдержкам, закрытый системный промпт.
- Ответы не формируются, если релевантные фрагменты из пяти локальных документов не найдены.
- В AI-контекст не передаются веб-результаты; только выдержки из `sources.json`.
- Для production: HTTPS, ограничение частоты запросов, логирование без персональных данных, защита от CSRF при cookie auth, лимиты затрат, регулярная юридическая актуализация и расширение корпуса.


## Тесты по этике государственной службы
Во вкладке «Практика» доступно 52 заранее подготовленных кейса трех уровней сложности, включая 16 новых кейсов по двум добавленным указам. Набор хранится в `data/ethics-tests.json`, сервер отдает его через `/api/tests`. Прохождение, перемешивание, проверка ответа и итоговая статистика выполняются в браузере без обращения к ИИ. Содержание кейсов и пояснения составлены по локальному корпусу документов из `data/sources.json`.

## Языки и оформление
- Интерфейс доступен на русском, казахском и английском языках. Выбор языка находится слева на верхней панели и сохраняется в браузере.
- Все 52 тестовых кейса имеют казахскую и английскую версии в `data/case-translations.json`; исходный русский набор в `data/ethics-tests.json` не перезаписывается.
- Названия НПА и реквизиты локализованы в `data/sources.json`. Для казахского интерфейса карточки открываются на казахской версии `adilet.zan.kz`; для русского — на русской. Для английского интерфейса используется английское название документа с переходом на официальную русскоязычную карточку Adilet.
- Ответ ИИ формируется на выбранном языке. Для поиска по русскоязычному локальному корпусу казахский или английский вопрос предварительно переводится на русский через настроенный AI API; анализ по-прежнему использует только локальные выдержки.
- Кнопка темы находится справа на верхней панели. Нажатия циклически переключают тёмную, светлую и системную темы. Выбор сохраняется в браузере; системный режим отслеживает `prefers-color-scheme`.

## Исправления v3.17 (язык и тема)

- Бейдж «ҚР» на главной был захардкожен: теперь «РК» / «ҚР» / «KZ» по языку.
- Для системной темы добавлена отдельная иконка ◐ (раньше она не отличалась от тёмной/светлой).

## Вкладка Q&A (v3.18)
- Новая вкладка «Q&A» в верхнем меню: 8 вопросов о работе сайта в виде раскрывающегося списка (на русском, казахском и английском). Тексты хранятся в массиве `FAQ` в файле `js/faq.js`; чтобы добавить или изменить вопрос, правьте этот массив — каждый элемент содержит `[ru, kk, en]` для вопроса и для ответа.

- На экранах до 560 px меню вкладок переносится во вторую строку, чтобы подписи не обрезались.

## Структура проекта (v3.20)
Код фронтенда разделён по ролям: **разметка — HTML, оформление — CSS, поведение — JavaScript**. Остальные файлы проекта (сервер, данные, скрипты запуска) остались на своих местах.

```
EthicsComitee/
├── index.html            ← ТОЛЬКО разметка (HTML): шапка, страницы-вкладки, футер
├── css/                  ← ДИЗАЙН (порядок файлов = порядок каскада, как в <head>)
│   ├── base.css          основа: цвета, шапка, навигация, hero, чат, карточки
│   ├── quiz.css          страница «Практика»
│   ├── common.css        загрузчик, ошибки, адаптив ≤850/≤650 px, ссылки на НПА
│   ├── theme-dark.css    тёмная тема
│   ├── effects.css       анимации и световой контур карточек
│   ├── theme-light.css   светлая тема
│   ├── faq.css           вкладка Q&A
│   ├── responsive.css    узкие экраны (≤560 px)
│   ├── utilities.css     утилитарные классы (вместо инлайновых style="…")
│   └── footer.css        футер (обе темы, адаптив)
├── js/                   ← КОД (порядок подключения важен, см. конец index.html)
│   ├── theme-init.js     ранняя инициализация темы (в <head>, без «мигания»)
│   ├── translations.js   словарь интерфейса [ru → kk, en]
│   ├── app.js            язык, тема, навигация, чат «Разбор», список документов
│   ├── quiz.js           страница «Практика»
│   ├── faq.js            вкладка Q&A (массив FAQ + отрисовка)
│   ├── footer.js         ссылка на «Әділет» на языке интерфейса
│   └── effects.js        плавное появление блоков
├── server.js             сервер и ИИ-запросы (не входит во фронтенд)
├── data/                 корпус НПА, тесты, переводы
└── README.md, package.json, start.sh/.bat, .env, .env.example
```
- Сервер раздаёт только `index.html`, `/css/*.css` и `/js/*.js` (расширение должно совпадать с папкой). `.env`, `server.js`, `data/` и всё остальное недоступны из браузера.
- Все скрипты — обычные (не модули) и делят общую область видимости, поэтому порядок `<script>` в конце `index.html` менять нельзя.

## Футер (v3.19)
Единый футер под всеми вкладками (`<footer id="siteFooter">` в `index.html`, стили — `css/footer.css`). Содержит: контакты, ссылку на ИПС «Әділет», ссылку на Google AI Studio (API), ИИ-сервисы, использованные при создании (Claude, ChatGPT), пометку об использовании ИИ, сведения об актуальности базы НПА, оговорку о неофициальном характере сервиса и предупреждение о передаче текста вопросов внешнему ИИ-сервису.
- **Контакты** меняются прямо в `index.html` (блок «Контакты»: ссылки `mailto:` и `tel:`). Сейчас телефон указан как `+7 000 0000` — замените на реальный номер (и в тексте ссылки, и в `href="tel:…"`).
- **Тексты на трёх языках** лежат в начале `js/translations.js` (раздел `/* --- футер --- */`): ключ — русский текст из `index.html`, значение — пара `[қазақша, English]`. При правке русского текста в HTML ключ в словаре нужно изменить так же.
- Ссылка на «Әділет» открывает версию портала на языке интерфейса (`js/footer.js`).
- Если вы смените ИИ-провайдера в `.env` (по умолчанию Google Gemini), обновите в футере упоминание «Google Gemini API» и ссылку на Google AI Studio.
- Строка об актуальности базы НПА намеренно написана как «подготовлена в 2026 году, не обновляется автоматически, сверяйтесь с действующей редакцией». Если вы выполнили и можете подтвердить сверку текстов с ИПС «Әділет» на конкретную дату, укажите эту дату в тексте.



## Исправление подсказок юридических терминов (v3.20)
- Всплывающее окно глоссария вынесено в `document.body` отдельным слоем: его больше не обрезают `overflow` карточек, панелей и контейнеров.
- Ширина подсказки увеличена до 560 px на широких экранах; высота ограничена видимой областью окна, длинный текст прокручивается внутри подсказки. На мобильных ширина адаптируется к экрану.
- Положение рассчитывается относительно окна браузера с проверкой всех четырёх границ; при нехватке места сверху подсказка открывается снизу. При прокрутке и изменении размера окна позиция пересчитывается.
- Добавлены явная кнопка закрытия, закрытие клавишей Escape, поддержка клавиатурного фокуса и сохранение возможности перейти к источнику. Данные подсказки вставляются через `textContent`, а не как HTML.
- Архитектурное правило для следующих обновлений: разметка — только в `index.html`, оформление — только в `css/*.css`, поведение — только в `js/*.js`. Не добавлять встроенные блоки `<style>`, `<script>` или inline-обработчики в HTML.
